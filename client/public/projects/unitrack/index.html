UNI-TRACK

A productivity and tracking web application for organising goals, habits, tasks and workflows in one practical interface.

Open UNI-TRACKView source code

The problem being explored

Personal plans and recurring activities can become scattered across notes, reminders and separate tools. UNI-TRACK explores how people can organise those activities and review progress in one coherent digital workspace.

Product areas

  • Organisation of goals, habits and tasks.
  • Activity and progress tracking.
  • Views intended to make ongoing work easier to review.
  • A responsive web experience designed around practical everyday use.

Engineering focus

The project explores application structure, interactive frontend workflows, data handling and privacy-conscious product decisions. Features and privacy properties should be evaluated against the current implementation rather than inferred from the product description alone.

Project scope

UNI-TRACK is an independent project. This page describes its intended product scope and does not claim universal privacy guarantees, a particular user count or independently measured productivity outcomes.
