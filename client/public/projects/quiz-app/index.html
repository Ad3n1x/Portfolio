Quiz App

An interactive learning application exploring subject practice, configurable quizzes and lightweight competitive learning experiences.

Open Quiz AppView source code

The problem being explored

Learning tools can be more engaging when learners can practise a topic, receive feedback and create questions that match what they want to revise. This project explores those interactions through a browser-based quiz experience.

Learning features

  • Practice in Mathematics, Physics and Chemistry.
  • Custom quiz creation and sharing.
  • Daily general-knowledge challenges.
  • A separate live multiplayer quiz mode.

Engineering focus

The project explores browser interactions, quiz state, question presentation, scoring and responsive user experiences. It is a learning project and is not presented as a formal assessment platform.
